# Contributing

This service follows the contribution rules of [Ostrun](https://github.com/ostrun-labs/ostrun/blob/main/CONTRIBUTING.md): stack versions, event contracts and the pull request process.

## Versioning

Tag format, semver for a service and the release flow are defined once, in [Versioning a service](https://github.com/ostrun-labs/ostrun/blob/main/CONTRIBUTING.md#versioning-a-service) in Ostrun's CONTRIBUTING. They are not repeated here. In short, the `version` in `ostrun.manifest.json` is bumped in a PR and the matching tag goes on the merged commit.
